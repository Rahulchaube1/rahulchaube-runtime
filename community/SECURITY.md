# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x.x | ✅ |

## Reporting a vulnerability

If you discover a security vulnerability in RahulChaube Runtime, please report it
privately to **security@rahulchaube.space**.

- Do **not** open a public issue for security vulnerabilities.
- Include a description, reproduction steps, and affected versions.
- We will acknowledge your report within 5 business days.
- A maintainer will be assigned as the primary handler and keep you informed of
  progress toward a fix and coordinated disclosure.

## Scope

This policy covers the RahulChaube Runtime CLI, the website, the API, the
installer, and bundled assets. It does not cover third-party dependencies unless
the vulnerability is exploitable through RahulChaube Runtime itself.
