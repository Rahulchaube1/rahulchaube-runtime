# Showcase

A gallery of projects and products built with **RahulChaube Runtime**.

> Want your project featured? Open a PR adding an entry to
> `showcase/projects.json`.

## Featured

| Project | Description | Stack |
| --- | --- | --- |
| Example API | Minimal JSON API | Hono |
| Example Web | Monorepo web app | React + workspace |
| Example CLI | Compiled command-line tool | rahulchaube build --compile |

## Submit your project

Add an entry to `showcase/projects.json`:

```json
{
  "name": "My Project",
  "description": "What it does.",
  "url": "https://example.com",
  "stack": ["react", "hono"]
}
```
