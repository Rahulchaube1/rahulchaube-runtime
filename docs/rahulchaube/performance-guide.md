# Performance measurements

The Benchmarks page reports fresh-process timings, executable size and peak resident memory on the published host. Each workload checks its output. npm runs the program through a Node package script. Use the same programs and versions to compare on your system.

```sh
python3 benchmarks/compare.py --samples 25 > results.json
```
