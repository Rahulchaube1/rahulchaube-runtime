# RC Runtime — Brand Guide

This document defines the visual and verbal identity for **RC Runtime**,
the standalone MIT-licensed JavaScript and TypeScript runtime by Rahul Chaube.

## Logo

| Asset | File | Use |
| --- | --- | --- |
| Primary (light) | `branding/logo.svg` | Light backgrounds |
| Primary (dark) | `branding/logo-dark.svg` | Dark backgrounds |
| Icon | `branding/favicon.svg` | Favicon, app icon, social |

Rahul Chaube’s folded lime-to-emerald mark contains the terminal prompt in its right half. The original artwork is [logo.png](logo.png). The website uses it on a deep green background in navigation, app icons and sharing previews. The homepage pairs its folded shapes with a TypeScript example and the output from the RC terminal.

Website icons preserve the mark’s proportions and gradient. To export them from the original file, install Pillow and run `python scripts/export_official_branding.py` from the repository root.

## Website colors and type

The logo backdrop is `#071a16`. Lime `#aee75a` and emerald `#199050` come from the original artwork. The website uses a GitHub-dark canvas (`#0d1117`), graphite panels, blue links and green RC highlights on every device. Action icons use the same palette and resource icons carry the diagonal fold from the mark. Geist is the site typeface and IBM Plex Mono is used for code and terminal output. Theme colors are defined in [globals.css](../website/app/globals.css).

## Voice

- Confident, modern, concise.
- Lead with speed, developer experience, and openness.
- Never claim the project is faster than Bun or Node unless a benchmark
  demonstrates it. Publish the workload and its measurements with any comparison.
